# Kanishkaa S. — Portfolio Website

A full-stack portfolio with Flask backend + SQLite database.

## Local Setup
```bash
pip install -r requirements.txt
python app.py
```
Open http://localhost:5000

## Admin Mode
Press `Ctrl+Shift+A` on the website → enter password → edit anything

## Deploy on Render
1. Push this folder to a GitHub repo
2. Go to render.com → New Web Service
3. Connect your GitHub repo
4. Render auto-detects render.yaml and deploys

## Change Admin Password
In render.com dashboard → Environment → change ADMIN_PASS value
